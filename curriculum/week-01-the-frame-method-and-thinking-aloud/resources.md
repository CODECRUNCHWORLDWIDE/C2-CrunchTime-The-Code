## Free practice platforms

**The problems in this course are written for this course.** You will not find the drills, the challenges, or their test cases on any of the sites below — that is deliberate, because a problem you can look up is a problem you can recall instead of solve.

What these platforms *are* good for is extra repetitions on the same **patterns**, and a judge to run against when you want instant pass/fail. Each drill ends with a "Practice elsewhere" line pointing at a problem in the same family, so use those as your entry points. Expect the contract to differ from ours; read theirs carefully rather than assuming.

Homework problem 3 sends you to one of these deliberately, to solve something genuinely unfamiliar.

- **LeetCode** — free tier is enough; filter by the "Two Pointers" tag: <https://leetcode.com/>
- **HackerRank — Interview Preparation Kit**: <https://www.hackerrank.com/interview/interview-preparation-kit>
- **Exercism — Python Track** (mentored, no judge pressure): <https://exercism.org/tracks/python>
- **Codeforces Educational** (more contest-flavored): <https://codeforces.com/edu/courses>

## Glossary cheat sheet

Keep this open in a tab.

| Term | One-line definition |
|------|---------------------|
| **FRAME** | The five-step problem-solving method this course is built around: Frame · Research constraints · Assess options · Make the solution · Examine |
| **Pattern** | A reusable problem-solving structure (two pointers, sliding window, etc.) |
| **Two pointers** | Move two indices through a sequence with controlled rules (often O(n)) |
| **Invariant** | A condition that remains true at every iteration of your loop |
| **Edge case** | Input shape that breaks the obvious algorithm (empty, single element, all duplicates, max size) |
| **Big-O** | Asymptotic upper bound; describes how runtime/space scales with input size |
| **In-place** | Algorithm that modifies its input directly, using O(1) extra space (modulo input itself) |
| **Pass** | One traversal of the input. "Single pass" = "O(n) time, see each element once." |
| **STAR** | Behavioral answer format: Situation, Task, Action, Result |
| **Mock** | A practice interview, usually 45 min, simulated as closely as possible to real conditions |
| **Onsite** | The 4-6 hour final interview round, traditionally on-site, now usually remote |
| **Whiteboard** | Live coding in a non-IDE environment (real whiteboard, Google Doc, shared Excalidraw) |
| **Behavioral** | Non-technical interview testing communication, judgment, teamwork |
