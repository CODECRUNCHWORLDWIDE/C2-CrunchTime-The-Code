# Week 2 — Challenges

Two stretch problems. Optional, but the gap between "comfortable hash-map user" and "interview-ready" lives here.

1. **[Challenge 1 — Subarray Sum Equals K](challenge-01-subarray-sum-equals-k.md)** — prefix sums + hash map; the canonical mid-level discriminator. ~90 minutes.
2. **[Challenge 2 — LRU Cache](challenge-02-lru-cache.md)** — `OrderedDict` or hash map + doubly-linked list; the canonical design problem. ~120 minutes.

Do them in order. The second is markedly harder than the first and crosses into design territory.
