# Week 3 — Challenges

One stretch problem. Optional, but it is the **hardest sliding-window problem in the standard interview canon**, and the gap between "comfortable with sliding window" and "interview-ready on sliding window" lives here.

1. **[Challenge 1 — Minimum Window Substring](challenge-01-min-window-substring.md)** — variable-size shape B + frequency invariant + `need/formed` counter. ~120 minutes.

Do it slowly. The first time you solve this, you will pause and re-read the spec twice. That's expected — the *invariant* takes longer to articulate than the code takes to write.
