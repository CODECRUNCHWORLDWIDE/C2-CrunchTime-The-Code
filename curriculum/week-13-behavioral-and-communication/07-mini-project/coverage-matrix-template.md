## Acceptance rules — verify both

**Rule 1 — every category column sums to ≥ 2.**

| Category | Column total | ≥ 2? |
|----------|:-:|:-:|
| Conflict | | [ ] |
| Failure | | [ ] |
| Leadership | | [ ] |
| Teamwork | | [ ] |
| Ambiguity | | [ ] |
| Pressure | | [ ] |
| Influence | | [ ] |
| Growth | | [ ] |

If any row above is unchecked, you have a **thin column**. Fix it: mine a new story for that category (Lecture 1 §6 interrogation questions), or find an existing story you can honestly re-frame to cover it (Lecture 2 §5). Influence and Conflict are the most commonly thin — check those first.

**Rule 2 — every story row (except the opener, slot 12) sums to ≥ 2.**

List any story whose row total is `1`:

- _____________________ (only covers: __________)

If any story (other than slot 12) covers only one category, it is **underused**. Fix it: re-interrogate the experience for a second competency and add the framing, or replace the story with a richer one.

---

## Gap analysis

After both rules pass, answer:

1. **Thinnest category** (lowest column total): ____________. If a target loop is known to weight this category, add a third story for it.
2. **Widest story** (highest row total): ____________. This is your lead story when you have a choice — it gives the most flexibility.
3. **Any single-point-of-failure category at exactly 2?** List them: ____________. These are fine, but be aware that burning one early leaves you with no backup choice for that category.
