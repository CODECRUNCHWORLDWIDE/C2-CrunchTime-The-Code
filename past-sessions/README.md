# Past Sessions

Archived materials from prior cohorts. These are preserved for historical reference — they are **not** the current curriculum. Active learners should use the [main 15-week curriculum](../curriculum/) instead.

## Sessions

- **[SPRING 2025](SPRING-2025/)** — The original *Crunch the Code* workshop series. Three units of Python fundamentals and interview-prep data structures, delivered as slide decks. The material predates the FRAME Method and the pattern-first week structure the course uses now.

## Why preserve these?

- **Historical context** — see how the program evolved from a workshop series into a fifteen-week interview-preparation course.
- **Reference material** — the fundamentals decks still stand on their own as a Python refresher.
- **Acknowledging contributors** — past instructors and TAs put real work into these materials.

## Why not delete them?

Open source curricula benefit from being able to compare versions over time. Even outdated material is useful for understanding pedagogical choices ("why did we change X?"). If a future cohort wants to revive an old unit's approach, it is right here.

## Contributing

We **do not** accept new contributions to past-session folders — they are frozen. Improvements should target the active [curriculum/](../curriculum/) tree.
