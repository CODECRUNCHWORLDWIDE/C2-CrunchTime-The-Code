# C2: Crunch the Code

Welcome to the **C2: Crunch the Code** workshop! This repository is your go-to resource for all materials, activities, and updates throughout the workshop. Whether you're a beginner or have some experience, this workshop is designed to help you develop a strong foundation in coding and cybersecurity concepts with practical hands-on skills.

---

## 🔗 Getting Started  

To participate in the workshop, please ensure you complete the following steps:  

### 1. Set Up Python and Jupyter Notebook in VS Code  

Follow these steps to set up your environment:  

#### **Step 1: Install Python**  
- Download and install Python from the [official website](https://www.python.org/downloads/).  
- During installation, check the box that says **"Add Python to PATH"**.  

#### **Step 2: Install Visual Studio Code (VS Code)**  
- Download and install VS Code from the [official website](https://code.visualstudio.com/).  

#### **Step 3: Install Required Extensions in VS Code**  
1. Open VS Code.  
2. Go to the Extensions Marketplace (Ctrl+Shift+X or Cmd+Shift+X).  
3. Search for and install the following extensions:  
   - **Python** (by Microsoft)  
   - **Jupyter** (by Microsoft)  

#### **Step 4: Set Up a Virtual Environment (Optional but Recommended)**  
1. Open a terminal in VS Code (Ctrl+` or Cmd+`).  
2. Create a virtual environment:  
   ```bash
